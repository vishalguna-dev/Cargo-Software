# Cargo Management System 🚚

A web-based Cargo Management System developed as a final year academic project to simplify cargo booking, shipment management, and tracking operations.

The system allows users to manage cargo bookings and monitor shipment status through a simple door-to-door tracking workflow.

---

## 📌 Project Overview

The application was designed to streamline cargo transportation processes by providing:

* Cargo booking management
* Shipment tracking
* Customer and shipment record handling
* Door-to-door delivery status updates
* Database-driven cargo information management

---

## 🚀 Features

* 📦 Cargo booking system
* 🚚 Shipment tracking functionality
* 📍 Door-to-door active tracking updates
* 🗂 Customer and cargo record management
* 🔍 Search and tracking support
* 💾 Database integration for persistent storage
